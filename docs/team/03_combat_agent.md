# 에이전트 2: 전투 시스템

## 역할
턴제 전투 로직, 스킬 시스템, 몬스터 정의를 개발한다.

## 책임 범위
- 턴제 전투 엔진 구현
- 몬스터 클래스 및 몬스터 데이터 정의
- 스킬 시스템 (직업별 고유 스킬)
- 전투 UI (텍스트 기반 전투 화면)
- 전투 보상 (경험치, 아이템 드롭)

## 산출물
| 파일 | 설명 |
|------|------|
| `Monster.h` | 몬스터 클래스 선언 |
| `Monster.cpp` | 몬스터 클래스 구현 및 몬스터 데이터 |
| `Skill.h` | 스킬 클래스 선언 |
| `Skill.cpp` | 스킬 클래스 구현 |
| `Combat.h` | 전투 엔진 선언 |
| `Combat.cpp` | 전투 엔진 구현 |

## 전투 흐름
```
전투 시작
  → 턴 시작 (속도 기반 선공 결정)
    → 플레이어 턴: 공격 / 스킬 / 아이템 / 도망
    → 몬스터 턴: AI 기반 행동 선택
    → 데미지 계산 및 적용
  → 승리 / 패배 / 도망 판정
전투 종료 → 보상 지급
```

## 몬스터 목록 (기본)
| 이름 | HP | 공격력 | 방어력 | 경험치 | 출현 층 |
|------|-----|--------|--------|--------|---------|
| 슬라임 | 30 | 5 | 2 | 10 | 1~2 |
| 고블린 | 50 | 10 | 5 | 25 | 2~3 |
| 스켈레톤 | 70 | 15 | 8 | 40 | 3~4 |
| 오크 전사 | 100 | 20 | 12 | 60 | 4~5 |
| 드래곤 (보스) | 200 | 30 | 20 | 150 | 5 |

## 데미지 공식
```
실제 데미지 = max(1, 공격력 - 방어력/2) * (0.8 ~ 1.2 랜덤 배율)
크리티컬 확률 = 민첩 * 2%  (최대 30%)
크리티컬 데미지 = 실제 데미지 * 1.5
```

## 협업 규칙
- 다른 에이전트의 모듈에 영향을 주는 변경이 필요할 경우, **해당 에이전트와 먼저 협의**한다.
- 특히 캐릭터 스탯/스킬 관련 변경 시 캐릭터 시스템(에이전트 1), 전투 결과 처리 시 던전 시스템(에이전트 3)과 반드시 사전 협의한다.
- 협의 후에도 의견이 합의되지 않으면 **설계자(메인 에이전트)에게 보고**하고, 설계자의 최종 결정에 따른다.

## 인터페이스 요구사항
- `Character` 객체를 받아 전투 수행
- 전투 결과(승리/패배/도망)를 반환
- 보상 지급 시 `Character`의 경험치/인벤토리 직접 수정
