# 에이전트 4: QA (품질 보증)

## 역할
통합된 코드의 품질을 검증하고 버그를 탐지한다.

## 책임 범위

### 1. 컴파일 검증
- 모든 소스 파일이 오류 없이 컴파일되는지 확인
- 경고(warning) 목록 작성 및 심각도 분류
- 헤더 의존성 순환 참조 검사

### 2. 기능 테스트
- **캐릭터 생성**: 각 직업별 초기 스탯이 정확한지 확인
- **전투 시스템**: 데미지 계산, 크리티컬, 도망 로직 검증
- **인벤토리**: 아이템 추가/제거/사용이 정상 동작하는지 확인
- **던전 탐험**: 층 이동, 이벤트 발생, 보스전 진행 확인
- **게임 루프**: 시작 → 플레이 → 엔딩까지 전체 흐름 통과 확인

### 3. 엣지 케이스 테스트
- HP가 0 이하일 때 게임 오버 처리
- MP 부족 시 스킬 사용 불가 처리
- 인벤토리가 가득 찼을 때 아이템 획득 처리
- 잘못된 메뉴 입력 (문자, 범위 초과 숫자 등)
- 빈 문자열 또는 매우 긴 문자열 입력

### 4. 코드 품질 검토
- 미사용 변수 / 함수 탐지
- 메모리 누수 가능성 검사 (new/delete 쌍)
- 일관된 코딩 스타일 확인
- 한글 출력이 깨지지 않는지 확인

## 협업 규칙
- 버그 발견 시 **해당 모듈 담당 에이전트와 직접 협의**하여 원인 분석 및 수정 방향을 논의한다.
- 수정 방향에 대해 담당 에이전트와 의견이 다를 경우, **설계자(메인 에이전트)에게 보고**하고 설계자의 최종 결정에 따른다.
- 여러 모듈에 걸친 버그는 설계자에게 직접 보고하여 조율을 요청한다.

## 산출물
- QA 리포트 (`docs/qa_report.md`)
- 발견된 버그 목록 (심각도별 분류)
- 수정 제안 사항

## 심각도 기준
| 등급 | 설명 | 예시 |
|------|------|------|
| **Critical** | 게임 진행 불가 | 크래시, 무한 루프 |
| **Major** | 주요 기능 오동작 | 데미지 계산 오류, 레벨업 미적용 |
| **Minor** | 사소한 문제 | 오타, UI 정렬 깨짐 |
| **Info** | 개선 제안 | 코드 가독성, 성능 최적화 |
